# Codex workflow

For change/build requests: make in-scope local changes and run relevant
validation without asking first. Ask only before external writes, destructive
actions, or material scope expansion.

For reports and reviews: lead with the conclusion. Include only the evidence
needed, material caveats, and the next action.

For changes: run relevant validation and report the commands/results. Do not
claim a check passed unless it was run successfully in the current workspace.
