# _audits

Workspace-level audits, plans, and analyses that don't belong to any
single project repo. Two naming conventions currently coexist here:

- **Untagged** (`ai-cli-discord-*`, `workspace-ai-automation-*`) --
  older documents following this workspace's general
  `lowercase-hyphens.md` convention. Not renamed or restructured by this
  README.
- **Timestamp-tagged** (`GUDocs_YYMMDD_HHMM_Author_Topic.md`) -- newer
  documents tied to a specific initiative, tracked below. Pattern
  borrowed from `GodsUnchained/Coach/audits/`
  (`Coach_YYMMDD_HHMM_Author_Topic.md`), with `GUDocs` standing in for
  `Coach` since this initiative isn't scoped to a single existing
  project.

## GUDocs -- public GU tools docs repo

Planning and execution record for splitting a curated, public-facing
documentation repo (`dumplingstrader/gu-tools-docs`) out of the private
`gaming` repo.

| Document | What it is |
|---|---|
| `GUDocs_260823_0618_Claude_PublicDocsRepoImplementationPlan.md` | The implementation plan -- task breakdown, ground rules, checkpoints |
| `GUDocs_260823_0906_Claude_PublicDocsRepoExecutionResults.md` | Execution record -- confirmed Task A table, Task B/G sign-offs, repo URL, Task D checklist output |
